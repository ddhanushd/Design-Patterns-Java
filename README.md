# Design Patterns in Java

This repository contains Java code demos for various **Design Patterns**. The patterns demonstrated here are essential to creating clean, maintainable, and scalable software. This project showcases examples of **Creational**, **Behavioral**, and **Structural Design Patterns**.

## Patterns Included

### 1. **Creational Design Patterns**
Creational design patterns deal with object creation mechanisms, trying to create objects in a manner suitable to the situation.

- **Singleton**  
  Ensures a class has only one instance and provides a global point of access to it.
  
- **Factory Method**  
  Defines an interface for creating an object, but allows subclasses to alter the type of objects that will be created.

- **Abstract Factory**  
  Provides an interface for creating families of related or dependent objects without specifying their concrete classes.

### 2. **Behavioral Design Patterns**

Behavioral design patterns are patterns that deal with algorithms and the assignment of responsibilities between objects.

- **Observer**  
  Allows a subject to notify its observers automatically of any changes in its state.

- **Strategy**  
  Allows a method to be selected at runtime from a family of algorithms.
